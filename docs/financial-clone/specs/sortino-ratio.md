# Sortino Ratio Calculator - Target & Downside Deviation

Manual matching-period simple returns or supplied arithmetic mean, fixed MAR and downside deviation. The downside denominator includes all N observations. No annual scaling, market-price retrieval, strategy ranking or future-return estimate.

The executable model lives at src/lib/calculators/sortino-ratio.ts. All reference input fields and examples are frozen in evidence/ratio-property-three-reference-inputs-20261118.json; independent Decimal expectations are generated by scripts/check-ratio-property-three-reference.py. Concepts and exclusions are explained in the calculation page, comparison guide and term.

Source: https://rpc.cfainstitute.org/sites/default/files/-/media/documents/code/gips/the-sortino-ratio.pdf

No competitor interface or live quote parity is claimed.
